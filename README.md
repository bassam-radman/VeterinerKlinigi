## Proje Açıklaması
Bu proje, Web Programlama dersi kapsamında
ASP.NET Core MVC ve .NET 10 kullanılarak
geliştirilen bir veteriner kliniği yönetim sistemidir.

## Kullanılacak Teknolojiler
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
- Bootstrap 5
- REST API
- MCP (Model Context Protocol)
